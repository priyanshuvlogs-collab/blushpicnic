# Blush Picnic — project conventions

Astro 7 (static output, `build.format: 'file'`, `trailingSlash: 'never'`) + Tailwind 4 + TypeScript. Deployed to Hostinger shared hosting (`public_html`), booking handled by `public/api/book.php` (PHPMailer over Hostinger SMTP, sending as support@blushpicnic.com to blush.picnic25@gmail.com).

## Non-negotiable content rules
- **Never invent facts.** No fake reviews, stats, awards, press, "spots left", years in business, numbers of picnics, team size, ratings, or policies. Only use facts in `src/content/settings.yaml`, `packages.yaml`, `addons.yaml` and the business brief. Where real content is missing, render a clearly marked placeholder (`.placeholder-note`, text starting "Placeholder —") and list it in `HANDOVER.md`.
- Every price says **"Starting at"** and **"before HST"**; package and occasion pages note that **location affects price** (`settings.locationNote`).
- Known facts: five services — picnics, proposals, room decor, birthday hamper delivery (at midnight or during the day), custom hampers ("DM with your vision"); deliver, set up, style, clean up (client takes their own food/drink waste); parks, beaches, backyards, homes, indoor venues; Toronto + GTA; reply within 5 hours (`settings.replyTime`); a travel fee by area is added to every quote (`settings.travel`, fees still unknown → "quoted by area"); glassware is not part of any package (add-on; tableware is styled for the look, disposable cutlery on request); picnic styles: classic low table included, table & chair setup and dome picnic quoted (`styles.yaml`); booking deposit $100 or 50% for larger events (non-refundable) + $100 refundable security deposit (returned within 24–48 hours after items are collected and checked); full payment before the event starts (setup begins once paid). Instagram + TikTok @blush.picnic.
- Owner's policies (use their substance; see /policies): unsafe weather (heavy rain, thunderstorms, high winds) → rescheduled to another available date, booking deposit applied to it, no refunds for weather cancellations; cancellations within 48 hours of the event not eligible for refund of payments made; client responsible for rental items (loss/damage deducted from security deposit, excess charged); client obtains any permits the park/venue requires; party poppers, confetti and glitter not permitted in public parks (client cleans up if used); setup and pickup times are arranged in advance and must be respected; 30–45 minute arrival grace period, later than 45 min without notice may be rescheduled; extra time subject to availability, requested before the booking ends, charged extra; please don't move or misuse the decor. Alcohol stance is still a placeholder.
- No secrets in git (SMTP/FTP passwords live in `blush-config.php` outside `public_html`, or GitHub Secrets).

## Data → never hard-code
All editable content is in `src/content/` (schemas in `src/content.config.ts`): `settings.yaml`, `packages.yaml`, `addons.yaml`, `styles.yaml` (picnic styles), `services.yaml` (the five services), `occasions/*.md`, `faqs.yaml`, `gallery.yaml`, `reviews.yaml`, `pages/*.md`, `booking-form.yaml`. Read it via helpers in `src/lib/site.ts` (`getSettings`, `getPackages`, `getAddons`, `getStyles`, `getServices`, `getOccasions`, `money`, `bookUrl`, `smsUrl`, `telUrl`, `occasionUrl`, `inlineMd`…). Changing a price must only ever mean editing one YAML file. JSON-LD builders live in `src/lib/schema.ts`. The booking form is defined in `src/content/booking-form.yaml` and resolved by `src/lib/form.ts` (`buildFormSchema`), which also produces `/api/form-schema.json` for the PHP validator.

Ids: services `picnics`, `proposals`, `room-decor`, `birthday-hampers`, `custom-hampers`; packages `simple`, `signature`, `proposal-romance`, `celebration` (+ pseudo `not-sure`); styles `classic`, `table-chairs`, `dome`; occasions are the filenames in `src/content/occasions/` (e.g. `proposal`), URL from frontmatter `urlSlug` (e.g. `/proposal-picnic-toronto`); pseudo occasion `other`. Deep links: `/book?occasion=proposal&package=proposal-romance`, `/book?service=room-decor`. Booking-form conditions: `showIf: {field, equals}` or `{field, in: [...]}` (same rule in `booking.ts`, `Validator.php` and the tests: `showIfMatches` in `src/lib/form.ts`); `lockBy` makes an answer follow another (occasion follows the service for proposals/hampers; browser only).

## Design system
- **Brand (Blush Picnic Logo Guide, concept 06 "The Basket")**: logo files in `public/brand/` (outlined SVGs extracted from the guide: `logo-horizontal` for the header, `logo-stacked`, `logo-stacked-reversed` for dark grounds, `logo-badge`, `logo-mark`, `logo-app-icon`, `logo-mark-small`). Use them through `Wordmark.astro` — never rebuild the wordmark in a font, recolour, stretch, add effects, or put the full-colour logo on a busy photo. Horizontal logo ≥ 240px wide where space allows. `npm run brand` regenerates favicons, app icons, `logo.png`, `logo.svg`, `brand/logo-email.png` and `og.jpg` from those SVGs (`/site.webmanifest` is built by `src/pages/site.webmanifest.ts`). Link any of these fixed-URL files through `versioned()` from `src/lib/brand.ts` (adds a `?v=` content hash so a new logo isn't hidden by caches).
- Palette (guide): Rose 700 #A14D4B, Blush 500 #E3A6A0, Blush 300 #EFC7C0, Blush 100 #F6E6E1, Sage 700 #4F6349, Sage 500 #8FA58A, Gold 500 #C49A5A, Cocoa 900 #3B2A26, Linen #FBF6F0.
- Tokens (`src/styles/global.css` `@theme`): `petal` (Blush 100) page bg, `petal-deep` bands, `cream` (Linen) surfaces, `cocoa`/`plum` (Cocoa 900 — `plum*` are legacy aliases) text and dark bands, `plum-soft` secondary text, `rose` primary buttons/accents (text-safe on petal/cream, not on petal-deep), `blush`/`blush-300`/`sage`/`gold` **decorative only**, `sage-ink`/`gold-ink` for coloured text, `line` hairlines. Fonts (guide): `font-display` = Cormorant Garamond 500/600 (headings only), body = Jost.
- Classes: `container-x`, `section-y`, `measure`, `btn btn-primary|btn-secondary|btn-light [btn-lg]` (primary = rose), `link-arrow`, `arch`, `arch-outline`, `prose-blush`, `heading-sm`, `label-caps` (the brand's spaced small caps, like the logo tagline — a few per page at most), `placeholder-note`, `hero-enter`.
- Shared components (`src/components/`): `BaseLayout` (title, description, image, jsonLd, noindex, hideStickyBar), `ArchImage`, `PriceTag`, `FaqList`, `CtaBand`, `Breadcrumbs`, `HowItWorks`, `ReviewsSection` (renders nothing when empty), `OccasionChips`, `Icon`, `Wordmark`.
- The arch (echoing the basket's handle) is the one signature motif — hero frames and sparingly elsewhere. Avoid AI-template tells: no all-caps eyebrow label on every section (`label-caps` sparingly), no grids of identical shadowed cards, no fade-up on every block (only `.hero-enter` on the hero). Respect `prefers-reduced-motion`.
- Images: `astro:assets` (`<Picture formats={['avif','webp']}>` / `ArchImage`), always meaningful `alt`, correct `sizes`. Placeholder photos live in `src/assets/photos/` (regenerate: `npm run placeholders`).
- Accessibility: WCAG 2.2 AA, tap targets ≥ 44px (`min-h-11`/`min-h-12`), visible focus, one `h1` per page, logical heading order, labelled controls, keyboard support for every interaction.

## Analytics
Call `window.bpTrack(event, params)` or add `data-track="<event>"` (+ `data-track-*` params) to links. Events: `booking_start`, `booking_step` {step}, `booking_submit`, `click_call`, `click_text`, `click_instagram`, `click_tiktok`, `package_select` {package}, `booking_cta` {location}, `link_click` {link} (/links page). GA4 / Meta Pixel load only after consent.

## Copy tokens
Never type prices, deposits or the phone number into copy. In occasion Markdown/frontmatter, `faqs.yaml` and `src/content/pages/*.md` use tokens from `src/lib/tokens.ts`: `{price:simple}`, `{price:signature}`, `{guests:celebration}`, `{hours:proposal-romance}`, `{extraGuest:signature}`, `{deposit}`, `{depositPercent}`, `{securityDeposit}`, `{replyTime}`, `{travelNote}`, `{locationNote}`, `{phone}`, `{text}`, `{email}`, `{instagram}`, `{tiktok}`… `getOccasions()`/`getFaqs()` return filled data; occasion bodies are filled in `[occasion].astro`. The build warns about typed `$` amounts.

## Commands
`npm run build` (set `OUT_DIR=dist-xyz CACHE_DIR=node_modules/.astro-xyz` to build in parallel without clobbering), `npm run check`, `npm run test:api` (PHP handler, every occasion), `npm run test:e2e` (Playwright booking flow), `npm test`, `npm run brand` (logo/icons/OG image), `npm run placeholders`, `npm run photos -- <folder>`, `./deploy.sh` (see docs/deployment.md). Docs: README.md (developers), HANDOVER.md (owner), SEO.md.
- `public/.htaccess` owns redirects, caching and the CSP — a new third-party service needs its domains added there. Don't name files in `public/` like `name.abcdefgh.ext` (they'd get immutable caching).
